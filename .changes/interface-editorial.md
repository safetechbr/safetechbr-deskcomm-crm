A interface passa a usar superfícies neutras, tipografia de sistema, controles monocromáticos, cartões arredondados e detalhes editoriais em coral e rosa. A linguagem visual é compartilhada por menus, formulários, tabelas, diálogos, atendimento, estoque e PDV. O dashboard recebe uma apresentação nova e atalhos compactos. Nome e logotipo da empresa permanecem os mesmos; esta camada de interface passa a determinar as cores dos controles.
